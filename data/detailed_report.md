## 3. 필터링 로직 (Filtering Logic)
### RegimeFilter 작동 원리
`RegimeFilter`는 현재 시장의 상태(Regime)가 전략이 허용하는 상태 목록(`allowed_regimes`)에 포함되어 있는지를 확인합니다.
- **입력 데이터**: 일별 시장 데이터의 `state` 컬럼 (예: 'GREEN', 'RED', 'NEUTRAL')
- **설정 (Config)**: `allowed_regimes: ['GREEN']`
- **로직**:
  ```python
  def check_filter(self, row, context):
      allowed = self.params.get('allowed_regimes', [])
      current_state = row.get('state', 'UNKNOWN')
      return current_state in allowed
  ```
- **의의**: 하락장('RED')이나 횡보장('NEUTRAL')에서 발생하는 거짓 신호(False Signals)를 원천적으로 차단하여 손실을 방지합니다.
