## 🔐 중요: 2단계 프로세스 (필수!)

### 1단계: 키움 로그인 (한 번만)

**먼저 키움 로그인 UI를 실행하세요:**

```batch
C:\Python39-32\python.exe scripts/kiwoom_login_ui.py
```

- 로그인 창이 뜨면 인증을 완료하세요
- 로그인 성공 후 **창을 닫지 마세요!** (백그라운드로 실행 유지)
- 이 프로그램이 실행 중일 때만 데이터 수집이 가능합니다

### 2단계: 데이터 수집

**로그인 후, 데이터 수집 스크립트를 실행하세요:**

```batch
# 배치 파일 실행 (권장)
수집_오전실행.bat

# 또는 직접 실행
C:\Python39-32\python.exe collect_kiwoom_400_v2.py
```

## ⚠️ 주의사항

### 🔴 중요 보안 규칙

1. **반복 로그인 금지**:
   - `kiwoom_login_ui.py`를 여러 번 실행하지 마세요
   - 하루에 1-2번만 로그인하세요
   - 반복 로그인 시 계정 차단 위험!

2. **로그인 UI 유지**:
   - 데이터 수집 중에는 로그인 UI를 닫지 마세요
   - 수집이 모두 끝난 후에만 닫으세요

3. **32비트 Python 필수**:
   - 반드시 `C:\Python39-32\python.exe` 사용
   - 64비트 Python은 키움 API와 호환 안 됨

4. **안정적인 네트워크**:
   - 수집 중 인터넷 연결 필요
   - WiFi보다 유선 연결 권장

5. **실행 중 종료 금지**:
   - Ctrl+C로 중단하면 다음 실행 시 이어서 진행

## 📞 문제 발생 시

### "키움이 로그인되어 있지 않습니다" 에러

**원인**: `kiwoom_login_ui.py`가 실행 중이지 않음

**해결**:

```batch
C:\Python39-32\python.exe scripts/kiwoom_login_ui.py
```

### "연결 상태 확인 실패" 에러

**원인**: 로그인이 만료되었거나 UI가 종료됨

**해결**: `kiwoom_login_ui.py`를 다시 실행하고 로그인

### 로그 확인

```batch
# 로그 파일 열기
notepad logs/kiwoom_collection_v2.log
```
