# System Architecture & Environment Report

**Date:** 2025-11-28
**Status:** Unified 32-bit Architecture

## 1. Executive Summary

To ensure stability and compatibility with the Kiwoom OpenAPI (which strictly requires 32-bit), the entire GARAM system has been unified to run in a **single 32-bit Python environment**. This eliminates complex inter-process communication between 32-bit and 64-bit processes and prevents "DLL load failed" errors.

## 2. Component Analysis

| Component | Function | Environment | Status | Notes |
| :--- | :--- | :--- | :--- | :--- |
| **Kiwoom Login** | Authentication, API Connection | **32-bit** | ✅ OK | Strictly required. Uses `QAxWidget`. |
| **Data Feed** | Real-time Data Collection | **32-bit** | ✅ OK | Writes to CSV. |
| **Dashboard Server** | Web UI, API Endpoints | **32-bit** | ✅ OK | Unified. Reads CSVs generated by Feed. |
| **Shadow Trader** | Trading Logic, Simulation | **32-bit** | ✅ OK | Runs within Server process. |
| **GPT-CSS Agent** | Logic Switching, LLM | **32-bit** | ✅ OK | Uses HTTP API (Ollama/LM Studio). No heavy local libs. |
| **AI Adapter** | Signal Scoring (XGBoost) | **32-bit** | ⚠️ Conditional | Uses `xgboost`. If 32-bit wheel missing, disables gracefully. |

## 3. 64-bit Necessity Check

User requested to identify if any component *must* use 64-bit.

* **Findings**: No critical component requires 64-bit.
  * **LLM**: Offloaded to external API (Ollama/LM Studio), so the Python client is lightweight.
  * **XGBoost**: Optional. If high-performance training is needed later, it can be done in a separate 64-bit offline process, saving models to JSON which the 32-bit runner can try to load (or skip).

## 4. Configuration & Startup

The system is controlled by `start_garam.bat`.

* **Variable**: `GARAM_PYTHON_32`
* **Default**: `python` (Assumes 32-bit is default or set in PATH)
* **Action Required**: User must ensure `GARAM_PYTHON_32` points to a valid 32-bit Python executable.

```batch
:: start_garam.bat Configuration
set GARAM_PYTHON_32=C:\Path\To\Your\Python32\python.exe
```

## 5. Verification

To verify the environment:

1. Run `start_garam.bat`.
2. Check the console output for:

    ```
    Using Python: [Your 32-bit Path] (Unified 32-bit Mode)
    ```

3. The Kiwoom Login window should appear.
4. The Dashboard should open.
